# Product Requirements

**Project:** Campus Parking Helper

**Team members:**

**Date:**

## User and problem

Who is the user?
people parking at on campus

What problem does the user have?
calculating parking fees quickly and accurately

## Goal

Our program will help the user:
quickly and accurately calculate parking fees
## Requirements

Write three things the program must do. Make each one specific enough to test.

1. The program must take in a number of hours.
2. The program must calculate a dollar amount based on the hours inputted.
3. The program must return the dollar amount to the user

## Not included

What will this version **not** do?

- Pay parking fees
- Store driver credentials
- Log hours
- change rate

## Success

We will know the product works when: Fees are calculated quickly and accurately
