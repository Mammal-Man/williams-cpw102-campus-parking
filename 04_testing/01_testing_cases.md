**Input / Action:**

**Expected Result:**

## Test Case 3: Invalid Input

**Input / Action:**  
Enter an invalid value (such as text when a number is expected)

**Expected Result:**  
The program handles the invalid input without crashing.

**Actual Result:**  
Program crashes

**Result:**  
Pass / **Fail**
